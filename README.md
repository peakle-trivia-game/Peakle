# Peakle - Daily Trivia Challenge

🌍 **Test your knowledge. Climb higher. Challenge your friends.**

Peakle is a fun browser-based trivia game that combines general knowledge, number comparisons, and strategic thinking.

🎮 **Play Now:** https://peakle.app/

## 📸 Game Preview

![Peakle Gameplay Screenshot](./s.png)

## ✨ Features

- Daily Trivia Challenges
- Unlimited Game Mode
- Geography and General Knowledge Topics
- Progressive Answer Challenges
- Personal Best Records
- Fun and Addictive Gameplay

## 🎯 How to Play

1. Visit Peakle and start a challenge.
2. Answer questions based on the selected topic.
3. Follow the challenge rules to keep progressing.
4. Try to reach the highest possible score.
5. Challenge yourself to beat your previous record!

## 🌍 Game Modes

- **Daily Mode:** Take on a new daily challenge.
- **Unlimited Mode:** Play whenever you want and explore different topics.
